# extropy.dev

My personal site. Next.js, TypeScript, Tailwind 4, next-intl (en, nl, ru, uk).

## Run

```bash
npm install
npm run dev
```

## Where stuff is

- `src/messages/*.json` - UI text for each language
- `src/content/notes/` - field notes
- `src/content/work/` - projects
- `src/lib/site.tsx` - links, email
